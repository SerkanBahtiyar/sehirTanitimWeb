# City Guide and Review Platform

A PHP and MySQL web application for discovering places, local food and historical attractions in a city, with user-generated reviews and feedback.

## Overview

The project brings city information together in one place. Visitors can explore destination and local-food content, while the application also includes pages for user feedback and administrative operations.

## Technology Stack

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Main Areas

- City and destination information
- Historical places and attractions
- Local food content
- User comments and photo-oriented content
- Complaint and feedback pages
- Administrative login and management pages

## Getting Started

1. Clone this repository.
2. Place the `WebProje` directory in your local PHP server's document root (for example, XAMPP's `htdocs`).
3. Create a MySQL database for the application.
4. Configure the database connection in `WebProje/baglanti.php`.
5. Import the required database tables and data if a database export is available.
6. Start Apache and MySQL, then open the project through your local server.

> Database credentials and user data should be kept private. The repository does not document a ready-to-import database backup.

## Notes

This is a source-code project intended to be run in a PHP/MySQL environment. A public hosted demo is not currently documented.
